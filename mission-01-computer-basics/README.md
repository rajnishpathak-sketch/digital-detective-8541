# Mission 1 – Know Your Computer

## 1. Mission Objective

The objective of this mission was to understand how a computer receives input, processes information, produces output and stores results. I also learned to identify hardware, software and computer-based systems used in everyday life.

---

## 2. Task 1.1 – Trace One Activity Using IPOS

**Activity chosen:** Typing and saving a document on my computer.

IPOS stands for Input, Processing, Output and Storage. It describes the four basic activities performed by a computer system.

| Stage | What happens in my example? | Hardware / Component |
|---|---|---|
| Input | I type text using the keyboard. | Keyboard |
| Processing | The CPU processes the keystrokes, while RAM temporarily holds the working data. | CPU and RAM |
| Output | The typed text appears on the display. | Screen |
| Storage | I save the document to the computer's internal storage. | SSD |

### What I Understood

A computer follows the IPOS cycle to perform tasks. When I type something, the computer receives my input, processes it and displays the result. When I save the document, the information is stored permanently.

I also understood that RAM is temporary memory used while programs are running, whereas an SSD stores files even after the computer is switched off.

---

## 3. Task 1.2 – Identify Hardware and Software

Hardware refers to the physical components of a computer that can be seen and touched. Software refers to the programs and instructions that tell the hardware what to do.

### Hardware and Software Table

| Item / Software Name | Hardware or Software? | Software Type | Purpose |
|---|---|---|---|
| Keyboard | Hardware | Not applicable | Used to enter text and commands |
| Display | Hardware | Not applicable | Displays visual information |
| CPU | Hardware | Not applicable | Executes instructions and processes data |
| SSD | Hardware | Not applicable | Stores files and applications |
| macOS | Software | Operating System | Manages computer resources and hardware |
| Disk Utility | Software | Utility | Helps manage and check storage devices |
| Safari | Software | Application | Used for browsing the internet |
| Visual Studio Code | Software | Application | Used for writing and editing code |

### What I Understood

I learned that hardware and software depend on each other to make a computer work.

I also understood the three main categories of software:

- **Operating System Software:** Manages computer hardware, memory and other resources. Example: macOS.
- **Application Software:** Helps users perform specific tasks. Examples: Safari and Visual Studio Code.
- **Utility Software:** Helps maintain, protect or manage the computer. Example: Disk Utility.

## 4. Task 1.3 – Computer Systems Around You

Computer-based systems are used in many everyday activities. They accept input, process information and produce output to perform specific tasks.

| System | Main Purpose | One Input | One Output |
|---|---|---|---|
| ATM | Performs banking transactions | PIN entered using keypad | Cash dispensed |
| Traffic Signal | Controls traffic flow | Timer or vehicle sensor signal | Red, yellow or green light |
| Ticket Vending Machine | Allows users to purchase tickets | Destination selection | Printed ticket |

### What I Understood

I learned that computer-based systems are not limited to laptops and mobile phones. Devices such as ATMs, traffic signals and ticket vending machines also use computing principles to perform everyday tasks.

They receive information, process it according to programmed instructions and generate the required output.

After completing this mission, I understood:

1. The basic working of a computer through the IPOS cycle.

## 6. Difficulties Faced and How I Resolved Them

Initially, I found it slightly difficult to distinguish between processing and storage because both are involved when working with data. I understood the difference by using the example of saving a document: RAM temporarily holds working data, while the SSD stores the saved file persistently.

I also needed to understand the difference between operating system, application and utility software. I resolved this by identifying the purpose of each program I regularly use on my MacBook.

Finally, I learned that everyday devices such as ATMs and traffic signals also follow the basic input-processing-output principle.
