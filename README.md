## About This Project

This repository contains my work for the Digital Detective Diwali Independent Learning Assignment. It is organised into eight learning missions (Missions 01–08), preceded by an initial setup mission (Mission 00). The missions cover computer fundamentals, terminal commands, operating systems, programming, number systems, Git and GitHub, and networking.

Each mission has its own folder and README file. The work for each mission is documented separately to maintain a clear record of the tasks completed, concepts learned, difficulties faced, and solutions.

## Running the Number Converter

The Mission 05 folder contains a Python program that converts a decimal number into binary and hexadecimal representations.

To run the program, open the repository in Terminal and execute:

```bash
python3 mission-05-numbers-data/number_converter.py
```

Enter a decimal number when prompted. The program displays its decimal, binary, and hexadecimal representations.

## What I Learned

Through these missions, I explored and practised:

- Basic computer hardware, software, and the input-process-output-storage cycle.
- Navigating the file system and managing files using terminal commands.
- Understanding operating systems, processes, permissions, and system information.
- Writing and executing a basic Python program.
- Number systems, including binary, decimal, and hexadecimal conversions.
- Using Git for version control, including commits, branches, and remote repositories.
- Using GitHub to host code and create pull requests.
- Networking fundamentals, including DNS, IP addresses, protocols, and client-server communication.
