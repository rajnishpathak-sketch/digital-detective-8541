### What is a Repository?

A repository (repo) is a storage location used to manage and track project files and their changes using Git. GitHub allows repositories to be hosted online and shared with others.

### Why Organise Files by Mission?

The project is organised into separate mission folders to keep files structured, make individual tasks easier to manage, and allow each mission to be completed and committed separately.

## 6. Setup Difficulties and Solutions

Initially, understanding multiline Terminal commands and the purpose of commands such as `mkdir`, `touch`, and `find` was challenging.

I resolved these difficulties by learning the purpose and syntax of each command and verifying the created folder structure using `find . -print`.
