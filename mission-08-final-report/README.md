## 5. My Understanding

Through this assignment, I learned how computers work, how to use the command line, and how an operating system manages computer resources.

I also learned basic Python programming, number-system conversions, and how Git and GitHub help developers manage code and track changes.

The networking mission helped me understand concepts such as IP addresses, DNS, routers, protocols, and how a browser communicates with a web server.

I also learned how to organise a programming project into folders, document my work using Markdown, and maintain a repository using Git.

Overall, this assignment helped me connect different computer science concepts with practical activities.

## 6. Difficulties Faced
- Initially, I was unfamiliar with several Terminal commands and their usage.
- Understanding Git branches, commits, staging and pushing changes took some practice.
- I found number-system conversions and their relationship with binary, decimal and hexadecimal representations challenging at first.
- Understanding networking concepts and how they work together required additional practice.
- Organising the repository and maintaining separate documentation for each mission required attention.

## 7. How I Resolved Them
- Practised Terminal commands and observed their outputs to understand how they work.
- Used `git status`, `git log` and other Git commands to understand the repository's state.
- Verified number conversions using Python's built-in functions.

- Created separate folders and README files to keep the project organised.
- Used the GitHub Pull Request page to understand how changes can be proposed and reviewed without merging them immediately.
